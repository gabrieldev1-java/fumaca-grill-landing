# Fumaça Grill — Landing Page

Landing page estática, responsiva e interativa feita sem banco de dados.

## Stack
- HTML5 semântico
- CSS moderno: Grid, Flexbox, `clamp()`, `backdrop-filter`, animações e responsive layout
- JavaScript vanilla: filtros, menu mobile, scroll reveal, lightbox e renderização dos cards
- Google Fonts

## Abrir
Abra `index.html` no navegador.

## Onde editar os dados
No topo de `script.js`, altere:
- `siteData.menu` para o cardápio oficial
- `siteData.reviews` para os comentários reais do Google
- `siteData.gallery` para as fotos oficiais do estabelecimento
